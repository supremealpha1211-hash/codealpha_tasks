# CodeAlpha - Task 1: Language Translation Tool 🌐

An AI-powered Language Translation Tool built for the **CodeAlpha Artificial Intelligence Internship**.

## 📌 Features
- **User Interface**: Clean, modern dark-themed web UI with reactive elements.
- **Translation Engine**: Supports 20+ world languages with auto-language detection via neural translation.
- **Text-to-Speech (TTS)**: Built-in voice playback for both input and translated text using browser speech synthesis.
- **Productivity Extras**:
  - One-click copy translation to clipboard
  - Dynamic character count tracker
  - Instant source/target language swap button
  - Clear text control

## 🚀 Getting Started

### 1. Prerequisites
- Python 3.9+
- Flask (`pip install -r requirements.txt`)

### 2. Installation & Running
```bash
cd CodeAlpha_LanguageTranslationTool
pip install -r requirements.txt
python app.py
```
Open your browser and navigate to:
```
http://127.0.0.1:5001
```

## 🛠 Tech Stack
- **Backend**: Python, Flask, urllib
- **Frontend**: HTML5, Modern CSS3, JavaScript (Fetch API, Web Speech API)
- **API**: Google Translate Neural Endpoint
